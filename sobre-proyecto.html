Cómo se hizo PokeConsultas

La página se construyó con HTML para organizar el contenido, CSS para darle estilo y JavaScript para consultar PokéAPI y mostrar los resultados.

HTML

El HTML organiza lo que ve el usuario. La cabecera contiene el logo y el nombre; el formulario permite escribir una búsqueda, y la tarjeta queda preparada para recibir los datos del Pokémon.

<form id="search-form">
  <input id="pokemon-search" type="search">
  <button type="submit">Buscar Pokémon</button>
</form>

<article id="pokemon-card" hidden>
  <h2 id="pokemon-name"></h2>
  <div id="pokemon-stats"></div>
</article>

Los id permiten que JavaScript encuentre los elementos que necesita actualizar. El atributo hidden oculta la ficha hasta que hay un resultado.

CSS

El archivo css/styles.css define colores, tamaños, espacios y distribución. Por ejemplo, Flexbox coloca el campo de búsqueda y el botón uno al lado del otro.

.search-row {
  display: flex;
  gap: 10px;
}

@media (max-width: 650px) {
  .search-row {
    flex-direction: column;
  }
}

La regla @media adapta el formulario a pantallas pequeñas para que los controles se acomoden verticalmente en un celular.

JavaScript

JavaScript espera que se envíe el formulario. Luego pide los datos, muestra el resultado y actualiza el mensaje si algo falla.

formulario.addEventListener("submit", async evento => {
  evento.preventDefault();
  const pokemon = await consultarPokemon(campoBusqueda.value);
  mostrarPokemon(pokemon);
});

PokéAPI

La función consultarPokemon está en js/app.js, junto al resto del JavaScript. Usa fetch para pedir información a PokéAPI por número o nombre.

const respuesta = await fetch(
  `https://pokeapi.co/api/v2/pokemon/${termino}`
);

También se consulta la especie para obtener el nombre en español. Después se revisa que el número esté entre el 252 y el 386. Si la petición falla o el Pokémon está fuera del rango, se muestra un mensaje en vez de una ficha.

La ficha

Cuando PokéAPI responde, la función consultarPokemon organiza los datos que necesita la página: número, nombre, imagen, tipos, habilidades, altura, peso y estadísticas base.

La función mostrarPokemon coloca los valores de texto en los espacios preparados en el HTML. Para la imagen, cambia el atributo src y añade un texto alternativo con el nombre del Pokémon.

Los tipos y las estadísticas pueden variar en cantidad y valor, por eso JavaScript los crea al recibir los datos. Primero limpia los resultados anteriores y luego agrega los nuevos elementos:

tipos.replaceChildren();
pokemon.tipos.forEach(tipo => {
  const etiqueta = document.createElement("span");
  etiqueta.textContent = tipo;
  tipos.append(etiqueta);
});

Las estadísticas se muestran con su nombre, su valor y una barra visual. La anchura de la barra se calcula comparando el valor con 255. La altura y el peso se dividen por 10 para convertir las medidas de PokéAPI a metros y kilogramos. Al final se quita hidden para mostrar la ficha completa.

En resumen

HTML organiza la página, CSS controla su apariencia y JavaScript consulta PokéAPI para mostrar la información. Los archivos están separados en las carpetas css, images y js.
